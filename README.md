# Сайт для заказа видео для машин

Простой и красивый сайт для приема заказов на видеосъемку автомобилей с интеграцией WhatsApp.

## Как использовать

1. **Откройте файл `script.js`**
2. **Найдите строку с `WHATSAPP_NUMBER`** (строка 3)
3. **Замените номер на ваш реальный номер WhatsApp**
   - Формат: код страны + номер без пробелов
   - Пример для России: `79001234567`
   - Пример с плюсом: `+79001234567` (плюс будет автоматически убран)

## Запуск сайта

Просто откройте файл `index.html` в браузере. Для локального запуска:

1. Дважды кликните на `index.html`
2. Или откройте через браузер: File → Open → выберите `index.html`

## Функциональность

- ✅ Выбор типа видео из 6 вариантов
- ✅ Кнопка "Заказать" для каждого типа
- ✅ Автоматический переход в WhatsApp с готовым сообщением
- ✅ Адаптивный дизайн для мобильных устройств
- ✅ Современный и красивый интерфейс

## Типы видео

1. **Обзорное видео** - полный обзор автомобиля
2. **Видео в движении** - динамичная съемка на дороге
3. **Рекламное видео** - профессиональная реклама
4. **Короткое видео для соцсетей** - для Instagram, TikTok
5. **Детальный обзор** - подробный обзор всех систем
6. **Премиум пакет** - полный комплект услуг

## Настройка

Вы можете изменить:
- Тексты описаний в `index.html`
- Цвета и стили в `styles.css`
- Номер WhatsApp в `script.js`
- Типы видео (добавить/удалить карточки в `index.html`)
