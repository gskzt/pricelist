# Инструкция по размещению сайта в интернете

## Вариант 1: Netlify (Самый простой) ⭐ РЕКОМЕНДУЕТСЯ

### Шаг 1: Подготовка
1. Убедитесь, что все файлы проекта на месте:
   - index.html
   - styles.css
   - script.js
   - Все видео файлы (.mp4, .MP4)

### Шаг 2: Размещение на Netlify
1. Зайдите на https://www.netlify.com
2. Нажмите "Sign up" (можно через GitHub, Google или Email)
3. После регистрации на главной странице:
   - Найдите секцию "Want to deploy a new site without connecting to Git?"
   - Перетащите всю папку проекта в окно браузера
4. Через 10-30 секунд сайт будет доступен по адресу:
   - `random-name-123.netlify.app`

### Шаг 3: Получение бесплатного домена
1. В панели Netlify: Site settings → Domain management
2. Нажмите "Add custom domain"
3. Введите желаемое имя (например: `video-mashin`)
4. Netlify предложит бесплатный поддомен: `video-mashin.netlify.app`

### Шаг 4: Подключение своего домена (опционально)
1. Купите домен на:
   - Namecheap.com (от $8/год)
   - GoDaddy.com (от $12/год)
   - Reg.ru (от 200₽/год для .ru доменов)
2. В Netlify: Site settings → Domain management → Add custom domain
3. Введите ваш домен (например: `vash-sait.kz`)
4. Netlify покажет DNS записи, которые нужно добавить в панели регистратора домена
5. Добавьте CNAME запись:
   - Имя: @ (или www)
   - Значение: ваш-сайт.netlify.app
6. Подождите 5-60 минут для активации

## Вариант 2: GitHub Pages

### Шаг 1: Создание репозитория
1. Зайдите на https://github.com
2. Создайте аккаунт (если нет)
3. Нажмите "New repository"
4. Название: `video-site` (или любое другое)
5. Выберите "Public"
6. Нажмите "Create repository"

### Шаг 2: Загрузка файлов
1. Установите Git (если нет): https://git-scm.com/downloads
2. Откройте терминал в папке проекта
3. Выполните команды:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ-USERNAME/video-site.git
git push -u origin main
```

### Шаг 3: Включение GitHub Pages
1. В репозитории: Settings → Pages
2. Source: выберите "main" branch
3. Folder: / (root)
4. Нажмите "Save"
5. Сайт будет доступен через 1-2 минуты по адресу:
   - `username.github.io/video-site`

### Шаг 4: Подключение домена
1. В Settings → Pages → Custom domain
2. Введите ваш домен
3. Добавьте файл `CNAME` в корень проекта с именем домена
4. Настройте DNS записи у регистратора домена

## Вариант 3: Vercel

1. Зайдите на https://vercel.com
2. Зарегистрируйтесь через GitHub
3. Нажмите "Add New Project"
4. Импортируйте репозиторий или загрузите файлы
5. Нажмите "Deploy"
6. Сайт будет доступен через несколько секунд

## Важные моменты

### Размер файлов
- Netlify: бесплатно до 100GB трафика/месяц
- GitHub Pages: бесплатно до 1GB репозитория
- Видео файлы могут быть большими - убедитесь, что они оптимизированы

### HTTPS
- Netlify, Vercel, GitHub Pages автоматически предоставляют SSL сертификат
- Ваш сайт будет доступен по https://

### Обновление сайта
- **Netlify**: просто перетащите новую версию файлов
- **GitHub Pages**: сделайте `git push` с обновлениями
- Изменения появятся через несколько секунд/минут
